# Redmine Client

Cliente de Redmine para web y desktop (móvil más adelante). Sirve para lo mismo que Redmine, con menos fricción:

- Configuras la URL de tu Redmine y tu API key una sola vez, y la app solo te muestra lo que puedes hacer.
- Filtras con una frase editable: *Tareas asignadas a mí en Abierta de Proyecto X*.
- Registras tiempo desde un cuadro pequeño, sin salir de la lista.
- Creas muchas tareas a la vez desde una plantilla de Excel.

## Empezar

```sh
cp .env.example .env
pnpm install
pnpm dev
```
